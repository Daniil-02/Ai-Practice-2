# Суперечності й прийняті рішення

| № | Суперечність або невизначеність | Моє рішення | Головна (✓) |
|---|---|---|---|
| 1 | Двоє гравців одночасно натискають «Записатися» на останнє вільне місце в основному складі рейду | Перевірка вільних слотів виконується на сервері під час збереження: перший запит займає місце в «Основі», а другий автоматично записується зі статусом «Резерв» і бачить відповідне повідомлення. | ✓ |
| 2 | Не визначено, чи може один гравець подати дві заявки на ту саму подію з різними ролями | Один учасник може мати лише одну активну заявку на конкретну подію; при повторному натисканні кнопка змінюється на «Скасувати заявку». | |
| 3 | Що відбувається із записаними гравцями, якщо офіцер зменшує ліміт місць події вже після того, як слоти заповнено | Зменшити ліміт місць нижче поточної кількості затверджених в «Основі» гравців система не дозволяє і виводить попередження біля поля ліміту. | |
| 4 | Не вказано, що бачать звичайні учасники на місці коментаря, який приховав офіцер після скарги | Замість тексту коментаря для всіх учасників відображається сірий напис «Повідомлення приховано модератором», а сам запис залишається в базі. | |
| 5 | Чи може учасник подати або скасувати заявку на подію, яку офіцер уже перевів у статус «Завершено» | Для подій зі статусом «Завершено» кнопки подання й скасування заявки, а також кнопки зміни складу для офіцера блокуються (стають неактивними). | |
